# Project: IsaacLab Lane Follower

## Vision
A self-driving mobile robot that autonomously navigates between two parallel lanes in an Isaac Sim environment.

## Goals
- Create a 2-lane simulation environment.
- Configure a robot with a forward camera sensor.
- Implement vision-based lane boundary detection.
- Develop a control loop for autonomous lane centering.

## Context
- **Framework:** NVIDIA IsaacLab / Isaac Sim.
- **Target:** Autonomous navigation (Lane following).
- **Key Files:** To be created (e.g., `lane_follower_env.py`).
