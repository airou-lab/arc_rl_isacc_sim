# Phase 5 Plan: Training & Policy Development

## Objective
Integrate the original ResNet18-based road-following policy with the Isaac Lab environment and verify autonomous performance.

## Strategy
The original policy (`road_following_model.pth`) expects a 224x224 RGB image and outputs a target coordinate. We will:
1.  Implement a wrapper for the policy in Isaac Lab.
2.  Update `ARCProEnvCfg` to provide the required visual observations.
3.  Implement the steering/throttle logic based on the policy's coordinate prediction.
4.  Verify lap completion in the `openStreetUSD` environment.

## Tasks
- [ ] **5.1: Policy Wrapper** - Create `arcproLab/mdp/policy_wrapper.py` to load the ResNet18 model.
- [ ] **5.2: Observation Integration** - Ensure `TiledCamera` observations are correctly pre-processed for the model.
- [ ] **5.3: Action Logic** - Implement the translation from model output (coordinates) to joint actions (steering angle, wheel velocity).
- [ ] **5.4: Inference Script** - Create a standalone script to run the environment with the policy for verification.

## Success Criteria
- Policy loads and performs inference at 30Hz+.
- Robot completes a full lap of the `openStreetUSD` track without leaving the lane.
- Visual debugging confirms the model's target predictions align with the road center.

## Verification Strategy
- **Unit Test:** Verify `policy_wrapper.py` can load the `.pth` file and perform a forward pass on dummy data.
- **Integration Test:** Run a single-robot inference session and record telemetry (lateral error).
- **UAT:** Visual confirmation of smooth navigation through the smart intersection.
