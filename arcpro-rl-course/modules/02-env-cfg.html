Scene Setup (Code)

Implementing the theory in arcpro_env_cfg.py.

Now let's look at how the GPU Physics Theory is practically implemented in the ARCPro codebase. Inside arcpro_env_cfg.py, we configure the exact timing and physical bounds of the GPU simulation.

ARCPRO_ENV_CFG.PY 
class ARCProEnvCfg(ManagerBasedRLEnvCfg):
    # Simulation physics step: 500 Hz
    sim_dt: float = 1.0 / 500.0
    
    # Control policy step: 50 Hz
    decimation: int = 10
PLAIN ENGLISH

Define the environment class inheriting from the RL Manager.

Physics Resolution: The integrator resolves rigid body collisions 500 times per simulated second (dt = 0.002s) to prevent object tunneling at high speeds.

Control Resolution: The neural network only infers actions every 10 physics steps (50 Hz). This mimics the real-world latency of the hardware controllers on the physical F1Tenth rover.
