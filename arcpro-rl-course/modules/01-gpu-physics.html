Part 1: The Simulation Environment

GPU Physics Simulation (Theory)

Breaking the CPU bottleneck in Reinforcement Learning.

Isaac Gym: High Performance GPU-Based Physics Simulation For Robot Learning (arXiv:2108.10470) Makoviychuk et al., 2021 (NVIDIA)

This foundational paper introduced the paradigm shift of keeping the entire RL pipeline—both the physics simulation and the neural network inference—on the GPU, bypassing the PCIe bus transfer bottleneck that crippled previous CPU-based physics engines like MuJoCo.

In ARCPro, the environment runs atop Isaac Lab (the successor to Isaac Gym). By representing physical states (position, velocity, collisions) as flattened PyTorch tensors living natively in VRAM, the system achieves simulation speeds orders of magnitude faster than real-time.

The Simulation Loop Matrix

Unlike single-agent CPU simulations, ARCPro vectorizes the simulation. The num_envs parameter (e.g., 16 or 4096) instantiates parallel universes. The physics engine computes the rigid body dynamics for all universes simultaneously via massively parallel matrix multiplication.
