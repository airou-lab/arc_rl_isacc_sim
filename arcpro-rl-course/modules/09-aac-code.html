Let's examine the network topology in skrl_models.py. Notice the stark difference in the dimensionality of the input layers between the Actor and the Critic.

SKRL_MODELS.PY (The Critic) 
class ARCProCritic(DeterministicMixin, Model):
    def __init__(self, observation_space, action_space, device):
        # Privileged Critic Head (MLP only, no vision)
        self.critic_head = nn.Sequential(
            nn.Linear(12, 256),
            nn.ReLU(),
            nn.Linear(256, 256),
            nn.ReLU(),
            nn.Linear(256, 1)
        )
MATHEMATICS

The Critic network approximates the Value Function $V(s)$.

Input dimensionality is strictly $S \in \mathbb{R}^{12}$. It completely bypasses the 512-dimensional ResNet image embeddings. It only observes exact coordinates, velocities, and tracking errors.

The output is $V \in \mathbb{R}^{1}$, representing the expected discounted return from the current state.

By contrast, the ARCProActor ingests $S \in \mathbb{R}^{524}$ (512 vision features + 12 telemetry features) to predict action distributions $\pi(a|s)$.
