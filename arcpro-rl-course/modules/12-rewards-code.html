Part 4: Optimization & Reward Math

The Code of Driving Smoothly (Code)

Implementing rewards in rewards.py.

Let's look inside rewards.py to see how driving behaviors are converted into PyTorch math for the PPO agent to optimize.

Staying Centered (Lateral Error)

REWARDS.PY 
def lateral_error_reward(env):
    lat_err = env.extras.get("lat_err", torch.zeros(...))
    abs_lat = torch.abs(lat_err)
    
    # Pure penalty
    reward = - (abs_lat * 10.0)
    return reward
PLAIN ENGLISH

To calculate the penalty for swerving...

Get the car's current distance from the centerline (e.g., -2 meters left, or 2 meters right).

Drop the negative sign. We only care about absolute distance (2 meters).

Multiply the distance by 10, and make it a negative penalty.

Suppressing the Jitters (Jerk Penalty)

Early AI drivers often oscillate wildly. We fix it by penalizing the difference between the current steering angle and the previous one, encouraging $C^2$ continuity.

REWARDS.PY 
def jerk_penalty(env):
    current = env.action_manager.action[:, 0]
    prev = env.extras["prev_action"][:, 0]
    
    steer_delta = current - prev
    return -100.0 * torch.square(steer_delta)
PLAIN ENGLISH

Get the steering angle the AI just requested.

Get the steering angle from the previous fraction of a second.

Find the difference between them.

Square the difference (this makes large, sudden jerks exponentially more painful) and multiply by -100.
