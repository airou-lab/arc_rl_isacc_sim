Implementing the State Space in Python.

Let's look at how the Quaternion math theory is implemented in observations.py, and how it is joined with visual data in train_skrl.py.

OBSERVATIONS.PY (Quaternions to Yaw) 
# Calculate yaw from quaternion q = [w, x, y, z]
q = asset.data.root_quat_w

yaw = torch.atan2(
    2.0 * (q[:, 0] * q[:, 3] + q[:, 1] * q[:, 2]),
    1.0 - 2.0 * (q[:, 2]**2 + q[:, 3]**2)
)
PLAIN ENGLISH

Retrieve the orientation tensor in $\mathbb{R}^4$.

To extract the 2D planar heading $\psi$ (yaw), we map the quaternion components to Euler space. The $\arctan2(y, x)$ function is used to preserve the correct quadrant $[-\pi, \pi]$.

Numerator: represents the sine component $\sin(\psi)$.

Denominator: represents the cosine component $\cos(\psi)$.

Fusing Vision and Telemetry

The yaw is combined with speed and position to form a 12-number telemetry array. But the real robot drives using a camera. Inside train_skrl.py, the SKRLFlattenWrapper uses a ResNet-18 neural network to crush a massive $256 \times 256 \times 3$ image into a dense 512-number array, and then glues it to the 12 telemetry numbers.

🧮
The Final State Vector

The final state $S$ passed to the Actor is exactly 524 numbers long: 512 (Vision) + 12 (Telemetry) = 524.
